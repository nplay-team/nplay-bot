# NPLAY-Bot (Levelbot)

This bot was created specifically for the Discord [server](https://discord.gg/qcpeZQhJf5) of the german YouTuber and Twitch Streamer [NPLAY](https://www.youtube.com/nplay). The core feature of this bot is a leveling system with a high level of customization. 
In addition, there are various temporary events, a karma system, rewards, a permissions system and many other useful features.
